platpy：用於多層次空間轉錄體學分析的空間優先框架

spatial-transcriptomicscomputational-biologypythonbioinformatics

bioRxiv · 10.64898/2026.05.26.727917

本研究提出了 platpy，這是一個基於 Python 的「空間優先」框架，將絕對物理微米座標視為所有資料類型的組織原則。該框架透過將形態學影像、轉錄本點雲、表達矩陣、分割細胞和使用者定義區域儲存為帶有自身空間元資料的型別化物件，使所有圖層在各種平台、解析度或分析操作下皆能保持自動對齊。這項工具透過 ViewPort 與 DataPort 介面簡化了多通道視覺化與原始資料提取，並支援區域特異性表達量分箱、皮質展開以及轉錄本與影像資料的亞微米級精細對齊等空間分析任務。platpy 的設計旨在與現有工具互補，以低記憶體佔用處理空間資料分析的複雜性與規模。
