A Multi-Omics Study of Cognitive Resilience to Alzheimer's Disease

阿茲海默症認知韌性的多體學研究

multi-omicsalzheimers-diseasecognitive-resiliencedementiaprefrontal-cortex

bioRxiv · 10.64898/2026.09.02.746746

阿茲海默症是最嚴重的失智症形式，過去研究多聚焦於風險因子與治療開發，對於認知韌性的神經生物學基礎與分子特徵著墨較少。本研究建立了一個由 282 位認知正常高齡者前額葉皮質所組成的世代，涵蓋配對的基因體、轉錄體與蛋白體資料。研究團隊進行了嚴謹的預處理與品質管制，包括序列指標檢核與跨體學樣本匹配。此資料集可作為探尋阿茲海默症認知韌性分子特徵的資源，並已免費開放給研究社群使用。

From code to natural language: MErlin - a multiomics toolkit for bacterial epigenomics delivered as Claude agent skill.

從程式碼到自然語言：MErlin——以 Claude 代理技能形式發表的細菌表觀基因體多體學工具組

bacterial-epigenomicsmethylomemulti-omicsbioinformaticsllm-agent

bioRxiv · 10.64898/2026.09.02.748773

這篇預印本介紹 MErlin（Methylation-driven Expression & Regulation Linkage in Interacting Nuclear-domains），一套專門用於解析細菌甲基體（methylome）的多體學工具組。細菌甲基體的詮釋涉及修飾鹼基註解、基因體註解、motif 清查、甲基轉移酶基因型、轉錄豐度、replichore 位置與染色體構形等多種異質資料，整合上極具挑戰。MErlin 包含十七個可組合的模組，從 modBAM 檔一路產出基因層級的排序證據與自含式 HTML 報告。除了傳統的 Python 套件形式外，作者也將其打包為 Claude 代理技能（agent skill），讓大型語言模型能以自然語言介面呼叫經審核的分析流程，而非自行生成新實作。研究團隊以合成資料集（內含已知真值）驗證其架構與統計方法，並以 Pseudoalteromonas haloplanktis TAC125 的甲基體—轉錄體比較展示對話式介面的實際應用。

MorphoNavigator-3D: Generalizable single-cell phenotyping of cancer spheroids using Bayesian-optimized deep-learning workflows

MorphoNavigator-3D：利用貝氏最佳化深度學習工作流程進行癌症球體之通用單細胞表型分析

single-cellcancerdeep-learningdrug-discovery3d-culture

bioRxiv · 10.1101/2024.09.08.611898

本研究提出 MorphoNavigator-3D（MoNa-3D）這項自動化框架，結合最佳化活細胞染色、深度學習分割與貝氏最佳化，實現複雜 3D 共培養中的高解析度、免標註單細胞分析。研究團隊將此方法應用於透明細胞腎細胞癌（ccRCC）與免疫細胞的 3D 球體共培養，以進行藥物篩選並提取多尺度表型特徵。分析結果成功解析了不同藥物引起的表型，例如 PI3K/mTOR 抑制劑促進球體解體、細胞核增大與免疫排斥，而免疫調節劑則維持球體架構與 T 細胞結合。這些發現確立了 MoNa-3D 作為可用於複雜 3D 多細胞系統之多維表型分析的通用平台。

RevPert: predicting candidate drivers of transcriptomic state transitions via gallery-native reverse perturbation

RevPert：透過原生反向擾動預測轉錄體狀態轉變的候選驅動因子

perturb-seqtranscriptomicscomputational-biologydrug-resistancereverse-perturbation

bioRxiv · 10.64898/2026.08.19.745674

細胞狀態轉變是適應、老化與疾病的基礎，但要從已收錄的基因擾動中找出最能解釋觀察到轉錄體變化的候選者，一直是個難題。本文提出 RevPert，一種原生反向擾動模型，結合帶正負號的皮爾森相關性與學習殘差，對固定基因目錄進行排序以匹配查詢對比 ΔY* = YB - YA。在 Replogle Essential Perturb-seq（四個細胞株）與 LINCS-KO 螢幕（十個細胞株）上，RevPert 在保留干預的恢復任務中表現領先。應用於 HCC 與 CML 的公開抗藥性對比時，雙臂排序將預設疾病錨點排在預期側，優於單純依差異表現量大小排序。整體而言，RevPert 將螢幕內反向排序與螢幕外帶正負號幾何檢查結合，後者用於校正文獻錨點，並非作為保留恢復的宣稱。
