A Systematic Evaluation of Single-Cell Batch Integration Metrics and sBEE, A New Metric

單細胞批次整合指標的系統性評估與新指標 sBEE

single-cellbatch-integrationbenchmarkingbioinformaticsscRNA-seq

bioRxiv · 10.64898/2026.04.22.720135

單細胞 RNA 定序 (scRNA-seq) 資料常因不同實驗室與條件產生批次效應，影響後續分析。雖然已有許多批次整合方法，但現有評估指標各自僅能捕捉批次混合的特定面向，且常假設每個細胞類型都存在於每個批次、批次組成平衡或叢集幾何形狀單純，這些假設在實務上經常不成立，導致不同基準研究對整合方法的排名出現分歧。本研究透過受控的合成情境，系統性地評估常用批次整合指標在批次組成不平衡、部分細胞類型重疊、叢集密度異質及不同幾何形狀等挑戰下的表現，揭示各指標的優勢、限制與失效模式。基於這些發現，作者開發了新指標 sBEE (single-cell Batch Effect Evaluator)，結合局部鄰域組成與跨批次距離關係，在單細胞層級評估批次混合程度，並在模擬與真實資料驗證中展現穩健性與可解釋性。

FOCUS: end-to-end preprocessing, alignment and resolution-matched integration of spatial multi-omics data

FOCUS：空間多體學資料的端到端前處理、對齊與解析度匹配整合

spatial-multi-omicsbioinformaticspythondata-integrationspatial-transcriptomics

bioRxiv · 10.64898/2026.08.04.742705

FOCUS 是一個開源的 Python 套件，提供空間多體學資料從原始實驗檔案到整合資料物件的端到端處理流程。該工具涵蓋空間轉錄體學、質譜影像、拉曼光譜影像以及明視野或螢光顯微鏡等模態，可進行模態特定的前處理、互動式空間對齊與解析度匹配註冊，最終輸出統一的 MuData 物件。FOCUS 採用模組化、基於註冊表（registry）的架構，方便擴充至其他資料模態。使用者可透過命令列介面、瀏覽器圖形介面或 Python API 三種方式存取此工具。

Move BeTween modAlities (MBTA) employs flow matching to predict single cell data modalities

Move BeTween modAlities (MBTA)：利用流匹配技術預測單細胞數據模態

single-cellcomputational-biologymulti-omicsflow-matching

bioRxiv · 10.64898/2026.08.05.743110

本研究提出了一種名為 MBTA 的計算框架，旨在解決單細胞生物學中不同分子模態間的結構不匹配問題。與傳統將模態強制整合至共享潛在空間的方法不同，MBTA 透過流匹配（flow matching）連接各模態的特定潛在空間，從而保留了各模態的結構完整性。在多模態單細胞數據集的基準測試中，MBTA 展現了優於現有方法的表現，特別是在結構差異顯著的數據集中。此框架能有效整合多種分子讀數，為構建細胞的多層次圖譜提供了計算基礎。

Virtual spatial transcriptomics from histopathology enables prognostic and therapeutic response prediction in cancer

透過組織病理影像進行虛擬空間轉錄體分析，以預測癌症預後與治療反應

spatial-transcriptomicshistopathologycancercomputational-biology

bioRxiv · 10.64898/2026.08.04.742671

研究團隊開發了名為 VISTA 的模型，能整合多尺度組織學特徵與空間背景，從常規 H&E 染色組織影像中推斷空間基因表現。此方法克服了空間轉錄體技術成本高昂與取得不易的限制，並在多項癌症研究中展現臨床應用潛力。VISTA 不僅能識別與存活率相關的基因及空間亞型，還能預測特定癌症治療的病理反應，為臨床腫瘤學提供了一種具成本效益的分析工具。
