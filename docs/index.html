高果糖玉米糖漿（HFCS）的攝取是肥胖與糖尿病的風險因子，但其特定器官層面的潛在機制尚未完全明瞭。本研究指出，專一性抑制小鼠小腸中的果糖分解，意外地能減輕果糖引起的肥胖與胰島素阻抗。此表型歸因於迴腸乳糜管（ileal lacteals）縮短而減少了膳食脂肪吸收。糞便移植實驗顯示，因宿主小腸果糖分解受阻而改變的微生物相，會減少對乳糜管生長至關重要的迴腸巨噬細胞。因此，改變的腸道乳糜管結構可能助長了高脂與高糖對代謝疾病的協同效應，這也可能與藥理學上抑制果糖分解能減輕飲食誘導之肥胖的臨床證據相關。
