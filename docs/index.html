Predicting clonal mutations from tumour spatial transcriptomics data using a graph convolutional neural network

利用圖卷積神經網路從腫瘤空間轉錄體學資料預測克隆突變

spatial-transcriptomicsgraph-convolutional-networktumor-heterogeneitymutation-prediction

bioRxiv · 10.64898/2026.07.08.737173

空間轉錄體學能揭示腫瘤生物學，但本身缺乏上游體細胞驅動突變資訊。研究團隊開發了名為 SPOT-Mut 的空間感知圖卷積神經網路方法，可直接從空間轉錄體學資料推斷突變的亞克隆。模型以模擬自大量現有 RNA 與配對 DNA 定序資料的虛擬空間轉錄體學切片進行訓練。SPOT-Mut 先針對人類癌症中最常突變的基因 TP53 進行評估，在多數分析的癌症類型中精確率與召回率均超過 95%，並以來自表皮鱗狀細胞癌連續切片的空間轉錄體學與配對 DNA 定序資料進行驗證。後續以 62 個常見突變驅動基因訓練，得到 40 個驅動基因的高表現體細胞突變預測模型，包含 KRAS、KEAP1、CTNNB1 與 APC。隨著空間轉錄體學資料與圖譜的增加，SPOT-Mut 有助於定位 TP53 等常見驅動突變的亞克隆變異。

Single-cell profiling quantifies the dose gap between population-average and complete pY-STAT1/3 suppression by JAK inhibitors

單細胞分析量化 JAK 抑制劑對 pY-STAT1/3 的族群平均與完全抑制劑量差距

single-celljak-inhibitorstat-signalingpharmacologydose-response

bioRxiv · 10.64898/2026.10.26.759076

研究以兩株人類單核細胞系為模型，在 IFN-γ 與 IL-10 刺激下，測定核內 STAT1 與 STAT3 酪胺酸磷酸化，並以六種 JAK 路徑抑制劑處理，共 24 組條件。作者比較算術平均抑制與單細胞反應 log10 轉換後平均的 log-mean 抑制，並與細胞離開刺激範圍的比例與進入未刺激範圍的比例相對照。於算術平均或 log-mean 抑制達至少 80% 的最低測試劑量，仍有中位數 76% 與 37% 的細胞維持在高於未刺激範圍的反應。結果顯示強烈的平均抑制下仍有相當比例細胞保留可觀的 pY-STAT 反應。log-mean 抑制大致對應部分抑制佔有率，而完全抑制佔有率的表觀 IC50 中位數較 log-mean IC50 高 2.4 倍、較算術平均 IC50 高 7.4 倍。作者指出此關係可作為從傳統抑制曲線估算細胞比例的經驗參考。

Single-cell RNA-seq of amniotic fluid provides unique insight into fetal development

羊水單細胞RNA定序描繪健康第二孕期胎兒細胞圖譜

single-cellamniotic-fluidfetal-developmentpreprint

bioRxiv · 10.64898/2026.10.26.762078

研究團隊以單細胞RNA定序建構首個來自健康第二孕期胎兒的羊水細胞圖譜。樣本來自七例染色體正常且結構正常的妊娠，採集週數為15至25週，全部順利產下健康嬰兒。分析顯示羊水中最豐富的細胞類型為胎兒皮膚細胞，其次為髓系與淋巴系細胞。比較較早（≤19週）與較晚（≥週）妊娠樣本，觀察到細胞組成隨孕齡變化，較晚樣本中肺上皮細胞比例增加，與肺發育的管腔期相符。對胎兒皮膚細胞進行差異基因表現分析發現第二孕期間的表現變化，相關訊號也在來自多種胎兒病理妊娠的獨立羊水資料集中富集。研究提供11,414個健康胎兒人類細胞的註解圖譜，並整合既有資料形成45,048細胞的胎兒細胞圖譜。

Spatialsnake: a flexible workflow for spatial transcriptomics analysis across platforms

跨平台空間轉錄組學彈性分析流程 Spatialsnake

spatial-transcriptomicsbioinformatics-workflowsingle-cellspatial-datasnakemake

bioRxiv · 10.64898/2026.10.27.762082

研究指出現有空間轉錄組學技術在解析度與資料輸出上各異，整合方法與針對特定族群或組織區域延伸分析常需額外腳本與重複資料準備。作者開發 Spatialsnake，一個以 SpatialData 與 Snakemake 建構的彈性流程，可分析 Visium、Visium HD、Stereo-seq、Xenium 與 MERFISH 的處理後輸出。流程提供共通指令列介面支援單一樣本與多樣本分析，並可調整參數與保存中間結果，使用者能選取族群、組織區域或距離基礎鄰域，重複聚類與註解並將精煉標籤映射回完整資料集。額外模組支援細胞型組成估算、空間域辨識、細胞間通訊推論、調控子分析與樣本層級比較，並以小鼠腦 Visium 與大腸直腸癌 Visium HD 資料集展示功能，其中三張大腸直腸癌切片的聯合分析保留 1,527,987 個 bins，並針對 223,632 個上皮 bins 進行後續分析。結論認為 Spatialsnake 為定序與影像基礎平台提供統一工作流程，兼顧全組織分析與選定細胞族群與組織區域的深入探討。
