研究團隊針對西藏高原養蜂戶鮮少見到瓦蟎的現象進行移地實驗。結果顯示，海拔超過3,500公尺的缺氧環境會降低瓦蟎的繁殖力並阻斷後代發育，因而阻止蟎群長期存續。將蜜蜂群體置於低海拔但模擬3,500公尺缺氧條件下，也觀察到相同的降低繁殖力與後代發育停滯現象。研究指出瓦蟎對低氧環境存在生理限制，這是先前未被認識的敏感性。作者認為此發現可能為開發無化學藥劑的蟎害控制方法提供方向，有助養蜂業與糧食安全。
